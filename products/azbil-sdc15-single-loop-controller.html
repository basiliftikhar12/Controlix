Azbil SDC15 Single Loop Controller

PKR 3,500

The Azbil SDC15 is a compact single-loop digital controller designed for reliable temperature and process control in industrial applications. It features a clear dual-display interface for monitoring the process variable (PV) and setpoint (SP), along with dedicated mode and parameter keys for convenient configuration and operation. The SDC15 supports a wide range of sensor and analog inputs, including thermocouples, Pt100/JPt100 RTDs, DC voltage, and 4-20mA current signals, depending on the selected configuration. Control methods include ON/OFF control and PID control using Azbil's advanced Ra-PID and Just-FiTTER algorithms. Depending on the model configuration, the controller can provide relay, current, voltage pulse, or continuous voltage control outputs, with additional event outputs and optional RS-485 communication available on supported versions. Its compact panel-mount design makes it suitable for temperature control, machinery, process equipment, ovens, heaters, and other industrial automation applications. The exact input, output, power supply, and communication configuration should be verified from the controller's complete model number before installation or replacement.

USB HART Modem SM100-C(III)

PKR 40,000

The Songmao SM100-C(III) is a USB-to-HART protocol converter that connects a PC to HART-compatible field instruments for configuration, calibration, and diagnostics. This is the Standard (USB) version, connecting directly to a computer via USB rather than the separate APP/wireless variant of this model. It provides RXD, TXD, and POW indicator LEDs for connection status and works with standard HART communicator software on Windows PCs.
